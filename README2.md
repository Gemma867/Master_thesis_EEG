# Project README

This repository contains the R code, saved model parameters, and figures corresponding to the different stages of the analysis.

The project is organized into four main directories:

```text
.
├── Exploratory analysis/
├── Comparison/
├── First model analysis/
└── Second model analysis/
```

## 1. Exploratory analysis

The `Exploratory analysis` directory contains the code used to perform the exploratory analysis of the EEG data.

```text
Exploratory analysis/
├── [R script]
└── figures/
    └── [generated figures]
```

The R script contains the code used to obtain the exploratory-analysis results and generate the corresponding figures.

The `figures` directory contains the figures produced by this analysis.

---

## 2. Comparison

The `Comparison` directory contains the analyses used to compare the results obtained from the different models and/or analysis conditions.

```text
Comparison/
└── ...
```

---

## 3. First model analysis

The `First model analysis` directory contains the code and results associated with the first state-space model.

```text
First model analysis/
├── figures/
├── First_model_analysis.R
├── Functions.R
├── Loop_first_model.R
└── parameters_6trials_junt.rds
```

### Files

- **`First_model_analysis.R`**  
  Contains the code used to analyse the results of the first model and generate the corresponding analyses and figures.

- **`Functions.R`**  
  Contains the R functions required by the first-model analyses.

- **`Loop_first_model.R`**  
  Contains the code used to run the first model over the selected trials/channels.

- **`parameters_6trials_junt.rds`**  
  RDS file containing the saved model parameters for the six analysed trials.

- **`figures/`**  
  Contains the figures generated from the first-model analysis.

---

## 4. Second model analysis

The `Second model analysis` directory contains the code, saved parameters, and figures associated with the second state-space model.

```text
Second model analysis/
├── figures/
├── parameters/
├── ACF_plots.R
├── Functions.R
├── Loop_second_model.R
├── Q_Q_plots.R
├── Q_R_phi_analysis_p1.R
└── VRR_and_power_reduction.R
```

### Files

- **`Functions.R`**  
  Contains the R functions required for fitting and analysing the second model.

- **`Loop_second_model.R`**  
  Contains the code used to run the second model over the selected trials/channels.

- **`ACF_plots.R`**  
  Contains the code used to generate the autocorrelation function (ACF) plots for analysing the model residuals.

- **`Q_Q_plots.R`**  
  Contains the code used to analyse and plot the process-noise covariance matrices and their associated results.

- **`Q_R_phi_analysis_p1.R`**  
  Contains the analysis of the estimated model parameters, including the process covariance (`Q`), measurement covariance (`R`), and autoregressive parameter (`phi`), for the corresponding model configuration.

- **`VRR_and_power_reduction.R`**  
  Contains the analysis of variance reduction and frequency-band power reduction resulting from the model.

- **`parameters/`**  
  Contains the saved parameters obtained from the second-model fitting procedure.

- **`figures/`**  
  Contains the figures generated by the second-model analyses.

---

## Reproducibility

The analyses are implemented in R. The scripts should be run from their corresponding directories, or with the working directory appropriately configured so that the required functions, parameter files, and output directories can be located.

The saved `.rds` files and the contents of the `parameters` directories contain previously estimated model parameters and can be used to reproduce the subsequent analyses without refitting the models.
